# 人生周历 · 微信小程序

「**余生很贵，请别浪费**」—— 把网页版「My Life in Weeks（人生周历）」迁移到微信小程序的版本。

- 一生按 **时间跨度 × 52 周** 排成圆点网格，每 10 年一块「方块」卡片
- **黑点 = 已过的一周**，**彩点 = 未来的一周**，**白圈 = 你正在度过的这一周**（呼吸动画）
- 首次打开引导设置出生日期与时间跨度（60/70/80/90/100 年可切换），选择自动记住
- 统计三卡片：已度过百分比 / 已过周数 / 剩余周数
- 点击任意周点，查看该周对应的日期与当时的年龄（整岁生日周有 🎉 提示）
- 18/30/60/80 岁生日周用金色圆点标记；统计下方有「今天是你来到世界的第 N 天 · 剩余约 M 天」
- 每日一句正能量格言；支持分享给好友与朋友圈；周点渐显动画

## 一、准备环境（首次）

1. 安装「微信开发者工具」：
   https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 获取 AppID：去 https://mp.weixin.qq.com/ 注册小程序（个人免费），或导入时选「测试号」

## 二、导入并运行

1. 打开「微信开发者工具」→ 点「**导入项目**」
2. 目录选择本文件夹（`miniprogram`）
3. AppID：填入你的真实 AppID，或选「**测试号**」
4. 点「确定」，工具会自动编译并在模拟器里预览
5. 真机预览：点工具顶部「**预览**」，用微信扫码即可在手机上打开

> 想正式上线让所有人使用，请按 [部署上线指南.md](部署上线指南.md) 操作
> （备案 → 上传 → 审核 → 发布）。

## 四、与原网页的差异说明

| 项 | 网页版 | 小程序版 |
|---|---|---|
| 页面标题 | MY LIFE IN WEEKS | 余生很贵，请别浪费 |
| 52 列圆点宽度 | 固定 10px（约 624px，手机超屏） | rpx 自适应，一屏放下 |
| 生日选择 | `<input type="date">` + 更新按钮 | 原生日期选择器，选完即时刷新（无按钮） |
| 首次打开 | 直接显示默认生日 | 引导页先选生日与时间跨度 |
| 时间跨度 | 写死 80 年 | 60/70/80/90/100 年可选 |
| 十年分组 | 写死 "10 Years" 标签 | 卡片「方块」+ 年龄区间标签（0–9岁 …） |
| 图例 | 无 | 黑点/彩点/本周 说明行 |
| 「现在」位置 | 无标记 | 黑白交界处白圈呼吸动画 |
| 统计 | 一行文字 | 三张卡片（百分比/已过/剩余） |
| 点击周点 | `alert` 显示日期 | 弹窗显示日期 + 当时年龄 |
| 分享 | 无 | 分享给好友 + 朋友圈 |
| 里程碑 | 无 | 18/30/60/80 岁生日周金色圆点 |
| 每日格言 | 无 | 页脚上方每天一句正能量短句 |
| 人生进度 | 无 | 统计下方「第 N 天 · 剩余 M 天」一句话 |
| 生日/跨度记忆 | 无 | 本地存储（存在每个用户各自的手机本地） |

> 颜色语义沿用原网页：**已过的周 = 黑色，未来的周 = 随机彩色**
> （黑 = 已消耗的人生，彩 = 尚未书写的人生）。
